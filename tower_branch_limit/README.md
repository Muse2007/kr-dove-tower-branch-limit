# 四级塔双分支限制（tower_branch_limit）

让 Dove 版的四级塔分支回到前三代原版的「两个分支」手感。

## 它做什么

原版前三代里，三级塔升四级时只有两个分支可选。Dove 版整合了三代防御塔，
同一个塔系（箭塔 / 法塔 / 炮塔 / 兵营）的四级分支有十几个，随便挑。

装上本插件后：

- **每个塔系，一局游戏内最多只能选用 2 种四级塔**（数量可配）。
- 用满 2 种之后，该塔系**其余四级塔分支会显示为本体的锁定图标**，不能再升级上去。
- **已经选中的那 2 种仍可继续建造**（想造几座游侠就造几座）。
- 四个塔系**各自独立计数**：箭塔用满了不影响法塔。

举例（箭塔，上限 2）：

| 局面 | 菜单表现 |
| --- | --- |
| 场上没有四级箭塔 | 18 个分支全部可选 |
| 场上有 1 座游侠 | 仍然全部可选（还没用满 2 种） |
| 有游侠 + 火枪 | 十字弩、图腾、矮人…… 全部锁定；游侠 / 火枪仍可选 |
| 卖掉火枪（ever 模式） | 依旧锁定（本局已经选过它了） |
| 卖掉火枪（current 模式） | 其它分支重新解锁 |

## 配置

在插件管理器里选中本插件点「配置」：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `max_branches_per_family` | `2` | 每个塔系最多可选的四级塔种类数。填 `0` 或负数 = 完全不限制（等于关掉本功能）。 |
| `lock_mode` | `"ever"` | `ever`：本局建造过就算占用，卖塔不解锁其它分支。<br>`current`：只算场上现存的种类，卖掉后其它分支重新解锁。 |
| `lock_chosen_too` | `false` | `false`：只锁没选过的种类，已选的能继续造。<br>`true`：用满后连已选的也锁，该塔系不能再造任何四级塔。 |

改完记得点「应用」——本插件实现了 `on_config_change`，可以热生效，不用重启游戏。

## 实现原理（只挂钩子，不改本体文件）

| 钩子 | 作用 |
| --- | --- |
| `TowerMenu.show` | 打开塔菜单前，把当前该锁的分支**临时**接在 `store.level.locked_towers` 后面，本体自己就会把它们画成锁定图标；菜单构建结束（含中途报错）立刻还原，绝不污染关卡数据。 |
| `TowerMenu.button_callback` | 记录玩家最终选中的分支（`ever` 模式的依据）；同时拦截极少数「菜单打开后塔系才被用满」造成的越权升级，并刷新菜单。 |
| `simulation.do_tick` | 兜底重挂：`TowerMenu` 是全局类，一旦被重新定义就自动重新挂上钩子。 |

判定「哪些分支该锁」的依据：

- 塔系来自 `kr1.game_settings` 的 `GS.archer_towers / mage_towers / engineer_towers / barrack_towers`，
  下标 `>= 4` 的即四级塔。**所以别的插件新增的四级塔也会被纳入统计**（例如狙击高台、四代法师塔）。
- 只处理「初级塔升到三级、准备挑四级分支」这一档菜单，一/二级塔菜单和四级塔自己的技能菜单不受影响。
- 本局记录挂在 `store.ephemeral` 上，换关 / 重开会自动清空。

## 已知行为与限制

- **不影响 F1 一键造塔面板和补丁的「随机塔模式」**（按需求保持原样）：
  用 F1 造出来的四级塔仍然会被算作「已选用的分支」；随机塔模式的下一个分支是随机的，
  不受本插件约束。
- 无尽模式同样生效（它走的是同一套塔菜单）。
- 只有「本局」限制，不影响存档、星级和其它模式。
- 若用无尽模式存档读档继续，`ever` 模式的历史记录会随 `store.ephemeral` 一起清空，
  此时按场上现存的四级塔重新计算。
